## 6. STUDENT'S ANALYSIS OF THE AI RESPONSE

Upon reviewing the AI-generated initial code, several critical bugs and limitations were identified by the student:

1. **Unbound Scope in Dynamic `exec()` Parsing**: The initial AI execution scope passed separate `globals` and `locals` dicts, causing recursive function calls (`fibonacci(n - 1)`) to crash with `NameError: name 'fibonacci' is not defined`.
2. **Unhashable Argument Errors**: The initial AI code generator added `@lru_cache` indiscriminately to function definitions, causing crashes when functions took unhashable list arguments (`unhashable type: 'list'`).
3. **Incorrect Syntax Error Trapping**: The AI code crashed when encountering invalid Python syntax rather than capturing syntax errors gracefully in AST parsing.
4. **Overestimated Power Calculation**: The original power formula generated by AI assumed static 65W consumption at all times without accounting for CPU idle state baseline vs active load delta.

---

## 7. MODIFICATIONS / IMPROVEMENTS MADE BY THE STUDENT

The following critical modifications were engineered to turn raw AI outputs into a production-grade application:

1. **Unified Namespace Execution Scope**: Fixed `core/dynamic_profiler.py` by passing a unified dictionary `exec(code_string, safe_scope, safe_scope)`, resolving recursive scope calls.
2. **Type-Aware Memoization Decorator**: Enhanced `core/ai_optimizer.py` regex matching to decorate ONLY scalar integer functions (e.g. `n`, `idx`, `count`), eliminating `unhashable type: 'list'` runtime crashes.
3. **Robust Syntax Error Guard**: Added try-except wrapper around `ast.parse()` inside `core/static_analyzer.py` returning structured JSON syntax error feedback.
4. **Dynamic CPU Load Telemetry**: Modified `core/dynamic_profiler.py` to capture real-time CPU percentage before and after execution using `psutil.cpu_percent()`:
   $$\text{Watts} = P_{\text{idle}} + (P_{\text{max}} - P_{\text{idle}}) \times \left(\frac{\text{CPU Utilization}}{100}\right)$$
5. **Comprehensive Test Suite**: Developed `tests/test_analyzer.py` covering static analysis, profiling accuracy, refactoring transformations, and SQLite persistence.
